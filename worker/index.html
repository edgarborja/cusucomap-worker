Activity log

    Backup (local download - never sent anywhere)

    Downloads a full snapshot of this worker's local database (spawns, raids, field research, subscribers, etc). Active spawns/raids/quests are trimmed automatically 2 hours after they expire, so this is the only way to keep older history if you want it.

    Field research

    Force-expires every currently active quest, so a fresh scan for the new day doesn't sit alongside yesterday's leftovers.

    Scheduled searches

    Loops through the scheduled search list via miniscord, resting between full passes - starts automatically when this page loads. Pausing here also happens automatically for the duration of a quest scan (see below), so the two never interleave on the same miniscord connection.

    Running

    Quest scan

    Runs one /questsearch call per row of a pasted list of scan-group centers (columns: Latitude, Longitude, Distance in meters, GroupMemberCount - order doesn't matter), through miniscord, spaced a few seconds apart. Covers both encounter and item rewards in a single call per location - no separate raid scan any more, since /gyms already polls every gym in the area continuously.
