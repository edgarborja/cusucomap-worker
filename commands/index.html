    Daily commands (each fires once per day, near the time shown)

      Area scan (one-time - runs now, doesn't touch the loop above)

      Covers a wide area by splitting it into many small, overlapping /pokesearch queries in a hex-packed pattern, since a single query caps out at a limited number of results. Sends immediately with priority over the worker's normal schedule; progress only shows up in the worker's own activity log, not here.

      Scan subscribers ("cusucos" - who can request a scan, and until when)

      Only npubs listed here (with a not-yet-expired date) can request an area/species scan of their own. Each gets a daily quota - 1 by default, or set "public tag" per npub to grant more (or fewer). Adding an npub already in the list updates its date/limit/tag instead of duplicating it; leaving daily limit blank resets it to the default, and it never resets that npub's quota usage for today. "Public tag" is shown to everyone on every spawn this npub shares, in place of their anonymous auto-generated code - leave it blank unless a subscriber has actually asked to be identified that way (e.g. a name or alias), since it replaces their anonymity.
